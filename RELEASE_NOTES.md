# css4j version 6.2.2 Release Notes

### November 8, 2026

This is mainly a bugfix release, with 6.2.2 being a drop-in replacement for 6.2.
All users are encouraged to upgrade.

Two serialization fixes were not ported to the minifier and this release fixes that.

Moreover the version and date of 6.2.1 release notes were wrong.

<br/>

## Detail of changes

- util: port serialization fix to minifier.
- build: update the top-level text files to convert the line ending.
